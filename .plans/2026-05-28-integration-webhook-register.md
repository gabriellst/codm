# Integration Webhook Registration on Activation — Implementation Plan

> **For agentic workers:** Execute via `/build`. Steps use checkbox
> (`- [ ]`) syntax for tracking. Each Task wraps one observable
> behavior in an outer RED→GREEN cycle (Matt Pocock vertical slicing).

**Goal:** When a Shopify sales-channel integration activates, the provider's order/product webhooks are registered automatically against our public Go ingest URL — idempotently, with retry-on-failure via the outbox.

**Architecture:** First a **Phase-0 contract lock**: a new `SyncEventName` TypeSpec enum in `packages/contracts` carrying all 10 canonical `sync.EventName` values, regenerated to Go + TS; Go's hand-written `internal/sync/enums/event_name.go` is **deleted** and its ~27 consumers substituted to reference the generated `wire.SyncEventName` directly (single source, no alias shim). Then a new per-`(type, platform)` `WebhookRegister` service-family (abstract + factory + mock + Shopify impl), mirroring the three factories already in the `integration` BC. A second, independent `EventHandler` subscribes to the existing `IntegrationActivatedEvent` (fan-out alongside the Go-bridge handler): it loads the `StoreIntegration`, opens its sealed credentials from the `CredentialVault`, resolves the per-platform register, and calls it. The Shopify impl maps each provider topic to a canonical `SyncEventName`, GETs existing webhooks, and POSTs only the missing topics — each to `${GO_WEBHOOK_PUBLIC_URL}/webhooks?platform&event&integrationId&storeId` (the exact query contract the Go intake controller validates) — so an outbox retry never duplicates.

**Tech Stack:** TypeScript, Bun, tsyringe, Zod, TypeSpec (contracts), Go, node fetch (injected for tests)

**Spec:** .specs/2026-05-28-integration-webhook-register-design.md
**Tasks:** 3
**Estimated minutes:** 190

Plus a cross-service contract-lock (T1) that authors `SyncEventName` in `packages/contracts`, deletes Go's hand-written enum, and substitutes its consumers to the generated `wire.SyncEventName`. No HTTP controller / Zod schema → **no SDK regen Contract Lock task** (the contract change is a wire *enum*, regenerated by `bun contracts`, not an OpenAPI/SDK operation). The webhook target URL is a config string, not a wire contract.

```typescript
import { Config } from '@template/core-typescript'
import type {
	StoreIntegrationType,
	SalesPlatform,
	CheckoutPlatform,
	PaymentGatewayPlatform,
	MarketingPlatform,
	InfoproductPlatform,
} from '@template/contracts-typescript/wire/enums'

export type WebhookRegisterPlatform =
	| SalesPlatform
	| CheckoutPlatform
	| PaymentGatewayPlatform
	| MarketingPlatform
	| InfoproductPlatform

/**
 * Per-platform webhook registration strategy. Dispatched by `(type, platform)`
 * via `WebhookRegisterFactory` — same shape as `HandshakeService` /
 * `OAuthCodeExchanger` / `AuthorizeUrlBuilder`.
 *
 * `registerWebhooks` must be IDEMPOTENT: a retry (outbox redelivery) must not
 * create duplicate provider-side webhooks. Failures throw
 * `WEBHOOK_REGISTRATION_FAILED`; the caller's outbox retries.
 *
 * `deleteWebhooks` is defined for symmetry (Disconnect teardown); no caller in
 * the current spec — the future Disconnect handler wires it.
 */
export abstract class WebhookRegister {
	abstract readonly type: StoreIntegrationType
	abstract readonly platform: WebhookRegisterPlatform

	abstract registerWebhooks(input: { credentials: Record<string, string>; storeIntegrationId: string; storeId: string }): Promise<void>

	abstract deleteWebhooks(input: { credentials: Record<string, string> }): Promise<void>

	/**
	 * Builds the public Go ingest URL the provider POSTs to. Matches the Go
	 * intake controller's required query params exactly
	 * (`packages/api/go/internal/webhooks/controllers/webhook.go`):
	 * `platform` (the platform enum value — `SalesPlatform.SHOPIFY === 'SHOPIFY'`
	 * already matches Go's WebhookPlatform set), `event` (a canonical
	 * `sync.external_*` event name), `integrationId` (the StoreIntegration id),
	 * `storeId`. One URL is built PER TOPIC — each carries its own `event`.
	 */
	static buildIngestUrl(input: { platform: WebhookRegisterPlatform; event: string; integrationId: string; storeId: string }): string {
		const params = new URLSearchParams({
			platform: input.platform,
			event: input.event,
			integrationId: input.integrationId,
			storeId: input.storeId,
		})
		return `${Config.env.GO_WEBHOOK_PUBLIC_URL}/webhooks?${params.toString()}`
	}
}
```

```typescript
import { injectable } from 'tsyringe-neo'
import { BaseError } from '@template/core-typescript'
import { SalesPlatform, StoreIntegrationType } from '@template/contracts-typescript/wire/enums'
import type { IntegrationApplicationErrors } from '../../errors'
import type { PlatformProps } from '../index'
import { WebhookRegister, type WebhookRegisterPlatform } from './WebhookRegister'
import { ShopifyWebhookRegister } from '../shopify/ShopifyWebhookRegister'

type PlatformForType<T extends StoreIntegrationType> = T extends StoreIntegrationType.SALES_CHANNEL
	? SalesPlatform
	: WebhookRegisterPlatform

type RegisterRegistry = { [T in StoreIntegrationType]?: Partial<Record<PlatformForType<T>, WebhookRegister>> }

/**
 * Per-(type, platform) resolver for WebhookRegister impls. Mirrors
 * `HandshakeServiceFactory` / `AuthorizeUrlBuilderFactory`: constructor-injected
 * impls, nested record keyed by the platform enum. `.get()` throws
 * `PLATFORM_NOT_SUPPORTED` for any platform without a register (marketing
 * platforms, and sales/checkout platforms whose impl isn't built yet).
 *
 * Shopify is the only impl today; add a provider = add a ctor param + table entry.
 */
@injectable()
export class WebhookRegisterFactory {
	private readonly registers: RegisterRegistry

	constructor(shopify: ShopifyWebhookRegister) {
		this.registers = {
			[StoreIntegrationType.SALES_CHANNEL]: {
				[SalesPlatform.SHOPIFY]: shopify,
			},
		}
	}

	get(platform: PlatformProps): WebhookRegister {
		// The correlated (type, platform) narrowing isn't provable across two
		// independent fields; cast to the loose record shape for the lookup —
		// the write-side table above is the type-level guarantee.
		const byPlatform = this.registers[platform.type] as Partial<Record<string, WebhookRegister>> | undefined
		const register = byPlatform?.[platform.platform]
		if (register === undefined) {
			throw new BaseError<IntegrationApplicationErrors>(
				'PLATFORM_NOT_SUPPORTED',
				`no WebhookRegister registered for ${platform.type}:${platform.platform}`,
			)
		}
		return register
	}
}
```

```typescript
// packages/api/typescript/src/integration/services/shopify/ShopifyWebhookRegister.ts
import { BaseError, tryCatchAsync } from '@template/core-typescript'
import { SalesPlatform, StoreIntegrationType, SyncEventName } from '@template/contracts-typescript/wire/enums'
import type { IntegrationApplicationErrors } from '../../errors'
import { WebhookRegister } from '../WebhookRegister/WebhookRegister'

const SHOPIFY_API_VERSION = '2024-07'

/**
 * Provider topic → canonical ingest `event`, sourced from the shared
 * `SyncEventName` contract enum (single source with the Go sync worker; Go's
 * intake controller `oneof`-validates the same values). Authored in T1.
 */
const SHOPIFY_TOPIC_EVENTS: Record<string, SyncEventName> = {
	'orders/create': SyncEventName.EXTERNAL_ORDER_UPDATED,
	'orders/updated': SyncEventName.EXTERNAL_ORDER_UPDATED,
	'products/create': SyncEventName.EXTERNAL_PRODUCT_UPDATED,
	'products/update': SyncEventName.EXTERNAL_PRODUCT_UPDATED,
	'order_transactions/create': SyncEventName.EXTERNAL_TRANSACTION_UPDATED,
}

interface ShopifyWebhook {
	id: number
	topic: string
}

/**
 * Shopify webhook registration. Lists existing webhooks
 * (GET /admin/api/{ver}/webhooks.json) and POSTs only the missing topics, each
 * with `address` = the Go ingest URL carrying that topic's canonical `event`
 * (built via WebhookRegister.buildIngestUrl). Idempotent on retry. Any non-2xx /
 * network / schema error throws WEBHOOK_REGISTRATION_FAILED. `fetchFn` is
 * constructor-injected for test isolation.
 */
export class ShopifyWebhookRegister extends WebhookRegister {
	readonly type = StoreIntegrationType.SALES_CHANNEL
	readonly platform = SalesPlatform.SHOPIFY

	constructor(private readonly fetchFn: typeof fetch = fetch) {
		super()
	}

	async registerWebhooks(input: { credentials: Record<string, string>; storeIntegrationId: string; storeId: string }): Promise<void> {
		const { shopDomain, accessToken } = this.requireCreds(input.credentials)

		const existing = await this.listWebhooks(shopDomain, accessToken)
		const existingTopics = new Set(existing.map(w => w.topic))
		const missing = Object.keys(SHOPIFY_TOPIC_EVENTS).filter(topic => !existingTopics.has(topic))

		for (const topic of missing) {
			const address = WebhookRegister.buildIngestUrl({
				platform: this.platform,
				event: SHOPIFY_TOPIC_EVENTS[topic]!,
				integrationId: input.storeIntegrationId,
				storeId: input.storeId,
			})
			const result = await tryCatchAsync(() =>
				this.fetchFn(this.webhooksUrl(shopDomain), {
					method: 'POST',
					headers: { 'content-type': 'application/json', accept: 'application/json', 'X-Shopify-Access-Token': accessToken },
					body: JSON.stringify({ webhook: { topic, address, format: 'json' } }),
				}),
			)
			if (!result.success) {
				throw new BaseError<IntegrationApplicationErrors>('WEBHOOK_REGISTRATION_FAILED', `Shopify webhook register network error: ${result.error.message}`)
			}
			if (!result.data.ok) {
				throw new BaseError<IntegrationApplicationErrors>('WEBHOOK_REGISTRATION_FAILED', `Shopify webhook register HTTP ${result.data.status} for topic ${topic}`)
			}
		}
	}

	async deleteWebhooks(input: { credentials: Record<string, string> }): Promise<void> {
		const { shopDomain, accessToken } = this.requireCreds(input.credentials)
		const existing = await this.listWebhooks(shopDomain, accessToken)
		for (const webhook of existing) {
			const result = await tryCatchAsync(() =>
				this.fetchFn(this.webhooksUrl(shopDomain, webhook.id), {
					method: 'DELETE',
					headers: { 'X-Shopify-Access-Token': accessToken },
				}),
			)
			if (!result.success || !result.data.ok) {
				throw new BaseError<IntegrationApplicationErrors>('WEBHOOK_REGISTRATION_FAILED', `Shopify webhook delete failed for id ${webhook.id}`)
			}
		}
	}

	private async listWebhooks(shopDomain: string, accessToken: string): Promise<ShopifyWebhook[]> {
		const result = await tryCatchAsync(() =>
			this.fetchFn(this.webhooksUrl(shopDomain), {
				headers: { accept: 'application/json', 'X-Shopify-Access-Token': accessToken },
			}),
		)
		if (!result.success) {
			throw new BaseError<IntegrationApplicationErrors>('WEBHOOK_REGISTRATION_FAILED', `Shopify webhook list network error: ${result.error.message}`)
		}
		if (!result.data.ok) {
			throw new BaseError<IntegrationApplicationErrors>('WEBHOOK_REGISTRATION_FAILED', `Shopify webhook list HTTP ${result.data.status}`)
		}
		const body = await tryCatchAsync<{ webhooks?: ShopifyWebhook[] }>(() => result.data.json())
		if (!body.success) {
			throw new BaseError<IntegrationApplicationErrors>('WEBHOOK_REGISTRATION_FAILED', 'Shopify webhook list returned non-JSON body')
		}
		return body.data.webhooks ?? []
	}

	private requireCreds(credentials: Record<string, string>): { shopDomain: string; accessToken: string } {
		const shopDomain = credentials.shopDomain
		const accessToken = credentials.accessToken
		if (!shopDomain || !accessToken) {
			throw new BaseError<IntegrationApplicationErrors>('WEBHOOK_REGISTRATION_FAILED', 'Shopify credentials missing shopDomain or accessToken')
		}
		return { shopDomain, accessToken }
	}

	private webhooksUrl(shopDomain: string, webhookId?: number): string {
		return `https://${shopDomain}/admin/api/${SHOPIFY_API_VERSION}/webhooks${webhookId !== undefined ? `/${webhookId}` : ''}.json`
	}
}
```

```typescript
// packages/api/typescript/src/integration/handlers/RegisterIntegrationWebhooksHandler.ts
import { injectable } from 'tsyringe-neo'
import { BaseError, CredentialVault, EventHandler, tryCatch } from '@template/core-typescript'
import { PlatformSchema } from '@integration/services'
import { IntegrationActivatedEvent } from '../events'
import { StoreIntegrationRepository } from '../repositories/StoreIntegrationRepository'
import { IntegrationCredentialSecretRepository } from '../repositories/IntegrationCredentialSecretRepository'
import { WebhookRegisterFactory } from '../services/WebhookRegister'

/**
 * Second, independent subscriber to `integration.store_integration.activated`
 * (the existing IntegrationActivatedHandler bridges the same event to Go).
 * Registers the provider's webhooks against the public Go ingest URL.
 *
 * Resolution order: load StoreIntegration → resolve the per-platform register
 * (skip silently when none exists — marketing/unbuilt platforms) → open the
 * sealed credentials → registerWebhooks. A register failure propagates so the
 * outbox retries; a vanished row / missing secret is a graceful no-op.
 */
@injectable()
export class RegisterIntegrationWebhooksHandler extends EventHandler<typeof IntegrationActivatedEvent> {
	readonly event = IntegrationActivatedEvent

	constructor(
		private readonly storeIntegrationRepo: StoreIntegrationRepository,
		private readonly credentialSecretRepo: IntegrationCredentialSecretRepository,
		private readonly vault: CredentialVault,
		private readonly registers: WebhookRegisterFactory,
	) {
		super()
	}

	async handle(event: this['input']): Promise<this['output']> {
		const integration = await this.storeIntegrationRepo.findById(event.payload.storeIntegrationId)
		if (integration === undefined) return

		// Re-parse to recover the correlated (type, platform) leaf — reading the two
		// fields off the entity decorrelates them (same narrowing the ConnectIntegration
		// / AuthorizeIntegration use cases do via PlatformSchema.parse).
		const platform = PlatformSchema.parse({ type: integration.type, platform: integration.platform })

		// Skip platforms with no webhook register (marketing, unbuilt) — not a failure.
		const resolved = tryCatch(() => this.registers.get(platform))
		if (!resolved.success) {
			if (resolved.error instanceof BaseError && resolved.error.name === 'PLATFORM_NOT_SUPPORTED') return
			throw resolved.error
		}
		const register = resolved.data

		const secret = await this.credentialSecretRepo.findByStoreIntegrationId(integration.id.value)
		if (secret === undefined) return

		const credentials = await this.vault.open<Record<string, string>>(secret.sealed)

		await register.registerWebhooks({
			credentials,
			storeIntegrationId: integration.id.value,
			storeId: integration.storeId.value,
		})
	}
}
```

## Notes

**Env var (new — set in deployment configs).** Add to `.env.example` and any deployed env:

```
GO_WEBHOOK_PUBLIC_URL=
```

Must be a **publicly internet-reachable** base URL for the Go webhook ingest (the provider POSTs to it). Defaults to `GO_WORKER_BASE_URL` (internal `localhost:3032`) for local dev where no real provider calls back — that default is non-functional for real provider webhooks and must be overridden in any environment that connects live stores.

**`deleteWebhooks` has no caller yet.** It's defined on the `WebhookRegister` contract + implemented in Shopify/Mock (per spec Decision 3, for symmetry). The Disconnect-teardown handler that calls it is a deferred follow-up (spec Out of Scope) — not in this plan.

**T1 contract-lock + marketing collision.** T1 authors `SyncEventName` in `packages/contracts` (regen via `bun contracts`), deletes the hand-written `packages/api/go/internal/sync/enums/event_name.go`, and substitutes its ~27 consumers to `wire.SyncEventName` — including the `sync/events/external_*` files the parallel marketing session authored (committed at `c663f3378`; may still be in flight). **Run T1 only when the marketing Go work is committed and the tree is quiet** — otherwise the codemod conflicts with their edits. After T1, a new sync event = one member in `sync-event-name.tsp` (the single source) + regen; consumers reference `wire.SyncEventName.*` directly. `WebhookPlatform` is intentionally left Go-only — the TS register uses the `SalesPlatform` value (`'SHOPIFY'`) directly for the `platform` param, so TS doesn't need it.

**Contracts regen.** `bun contracts` = `cd packages/contracts && bun run all` (tsp:compile → wire codegen TS+Go → drizzle:generate). It rewrites `packages/contracts/generated/**`; commit or stash-free before running (do not `git stash` across it).

**`StoreIntegration` cross-context reads.** This handler stays inside the `integration` BC: it reads `integration`-owned `StoreIntegration` + `IntegrationCredentialSecret` only. No tenancy/Store access here (that's Spec B).
