# Marketing Canonical Aggregates — Go Write-Side (Spec β.1) — Implementation Plan

> **For agentic workers:** Execute via `/build`. Each Task wraps one observable
> behavior (a layer landed across all 6 aggregates) in an outer gate
> (compile + targeted tests). The sibling pattern is canonical — workers
> mirror the existing Order shape.

**Goal:** Land the canonical Go-write-side aggregate model for marketing
(BusinessAccount → AdAccount → Campaign → AdSet → Ad + AdSpend buckets) so
Spec γ+ Facebook/Google/TikTok pipelines can persist their normalized output
via the existing handler-and-storage-drain pattern.

**Architecture:** 6 new aggregates in `packages/api/go/internal/sync/entities/`
following the existing Order pattern (private fields + XInput normalizer
struct + `NewXFromProviderPayload` constructor + `Id.fromSeed` deterministic
PK). Each gets a Drizzle table (sync schema), a pgx repository (idempotent
UPSERT), an internal Go event, a handler, a storage drain, and fx wiring.

**Tech Stack:** Go 1.24+ (uber/fx, pgx/v5), TypeScript Drizzle (`packages/contracts/db/schema/sync.ts`),
Bun (`bun migrate:create`, `bun migrate:dev`, `bun run test`, `bun tsc`).

`syncAdSets`:
- Same as Campaign PLUS
- `campaignExternalId varchar not null`
- Unique on `(platform, externalId)`

`syncAds`:
- Same as AdSet PLUS
- `adSetExternalId varchar not null`
- Unique on `(platform, externalId)`

`syncAdSpends`:

- `startDate timestamp not null`, `endDate timestamp not null`
- `groupBy varchar not null` (AdSpendGroupBy values: HOURLY / DAILY)
- `spendCents bigint not null`
- timestamps
- Unique on `(platform, adAccountExternalId, campaignExternalId, startDate, endDate, groupBy)` — defensive composite even though id IS deterministic from these

### Step T2.1 — Create the 6 entity files

Each file mirrors the Order shape:

```go
package entities

import (
    "time"
    wire "template/contracts-go/wire"
    coreobjects "template/core-go/objects"
)

type BusinessAccount struct {
    id                coreobjects.ID
    platform          wire.MarketingPlatform
    externalID        string
    name              string
    status            wire.BusinessAccountStatus
    externalCreatedAt time.Time
}

type BusinessAccountInput struct {
    Platform          wire.MarketingPlatform
    ExternalID        string
    Name              string
    Status            wire.BusinessAccountStatus
    ExternalCreatedAt time.Time
}

func NewBusinessAccountFromProviderPayload(input BusinessAccountInput) (*BusinessAccount, error) {
    // Basic invariant: ExternalID + Platform must be present
    if input.ExternalID == "" {
        return nil, fmt.Errorf("BusinessAccount.ExternalID is required")
    }
    if input.Platform == "" {
        return nil, fmt.Errorf("BusinessAccount.Platform is required")
    }

    id, err := coreobjects.IDFromSeed(string(input.Platform), input.ExternalID)
    if err != nil {
        return nil, fmt.Errorf("BusinessAccount.id: %w", err)
    }

    return &BusinessAccount{
        id:                id,
        platform:          input.Platform,
        externalID:        input.ExternalID,
        name:              input.Name,
        status:            input.Status,
        externalCreatedAt: input.ExternalCreatedAt,
    }, nil
}

// Getters
func (b *BusinessAccount) ID() coreobjects.ID               { return b.id }
func (b *BusinessAccount) Platform() wire.MarketingPlatform { return b.platform }
// ... etc
```

Apply the analogous pattern for the other 5 aggregates per the spec's Decision 1 field lists. The AdSpend id seed combines `(platform, adAccountExternalId, campaignExternalId, startDate.Format(time.RFC3339), endDate.Format(time.RFC3339), string(groupBy))`.

### Step T4.3 — Create 6 storage drain files

Each storage:

```go
package businessaccount

import (
    "context"
    "log/slog"
    "template/api-go/internal/sync/entities"
    barepo "template/api-go/internal/sync/repositories/businessaccount"
)

type Storage struct {
    repo  barepo.BusinessAccountRepository
    inCh  chan *entities.BusinessAccount
}

func NewStorage(repo barepo.BusinessAccountRepository) *Storage {
    return &Storage{repo: repo, inCh: make(chan *entities.BusinessAccount, 256)}
}

func (s *Storage) Enqueue(ba *entities.BusinessAccount) {
    s.inCh <- ba
}

func (s *Storage) Start(ctx context.Context) func() {
    done := make(chan struct{})
    go func() {
        defer close(done)
        for {
            select {
            case <-ctx.Done():
                return
            case ba := <-s.inCh:
                if err := s.repo.Save(ctx, ba); err != nil {
                    slog.Error("BusinessAccount storage save failed", "error", err)
                }
            }
        }
    }()
    return func() { <-done }
}
```
