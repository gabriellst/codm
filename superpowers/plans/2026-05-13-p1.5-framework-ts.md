# P1.5 — Extract framework/ts from packages/api/ts/src/shared/

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **No reviewer subagents** per `feedback_skip_reviewer_subagents` memory — controller self-verifies each commit via diff inspection.

**Goal:** Lift context-agnostic architectural primitives out of `packages/api/ts/src/shared/` into a new `packages/framework/ts/` workspace package. Rewire `packages/api/ts` to import from `@template/framework-ts` instead of `@shared/*`. Delete medscall-leftover Brazilian VOs (CPF, CNPJ, RG, BirthDate, Phone, PhoneBuilder, ZipCode) and BrazilianState enum (the only context-specific code remaining from clean-2).

**Architecture:** Framework is a workspace member with `main: "./src/index.ts"` (no build step — Bun resolves TS workspaces natively). It exports area-scoped barrels: `@template/framework-ts/schema`, `/events`, `/entities`, `/objects`, `/mediators`, `/unitofwork`, `/outbox`, `/repositories`, `/http`, `/openapi`, `/tracing`, `/errors`, `/db`, `/utils`. `api/ts` keeps bounded contexts (auth, game, ui) but their imports point at framework.

**Tech Stack (unchanged from current api/ts):** Bun, Zod ^4, drizzle-orm ^0.45, tsyringe-neo, fastify, opentelemetry, eventemitter2, ioredis. Framework is a peer (workspace TS package) — no new runtime deps.
