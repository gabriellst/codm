# P1.8 — Refactor contracts codegen to use framework

**Goal:** Drop the stopgap helpers in contracts (`generated/ts/src/wire/_z.ts`, `generated/rs/src/integration_event.rs`). Refactor `emit-wire-ts.ts` to emit class wrappers extending `framework/ts/events/BaseIntegrationEvent`. Refactor `emit-wire-rs.ts` to use the real proc-macro `integration_event!` from `framework/rs/macros` with z.* DSL.

## TS emitter changes

**Drop:** `packages/contracts/generated/ts/src/wire/_z.ts`

**New emission shape** (per event file):
```typescript
import { BaseIntegrationEvent } from '@template/framework-ts/events'
import { z } from '@template/framework-ts/schema'

/** Triggers transcoding. */
export const VideoUploadedEventSchema = z.integrationEvent({
	videoId: z.string(),
	channelId: z.string(),
	uploadedBy: z.string(),
	byteSize: z.number().int(),
	mimeType: z.string(),
	storageKey: z.string(),
})

export class VideoUploadedEvent extends BaseIntegrationEvent<typeof VideoUploadedEventSchema> {
	static override readonly name = 'integration.video.uploaded' as const
	static readonly schema = VideoUploadedEventSchema
}
```

**Reasons matching existing pattern (from `clean-2:packages/api/ts/src/shared/events/GameCreatedIntegrationEvent.ts`):**
- `z.integrationEvent({ ...payload })` — payload-only signature; framework's helper supplies the envelope.
- Class extends `BaseIntegrationEvent<typeof Schema>` with `static name` (the wire identifier) and `static schema`.

**Discriminated union barrel** stays similar:
```typescript
import { z } from '@template/framework-ts/schema'
import { /* all event classes + their schemas */ } from './_imports'

export * from './video-uploaded'
// ... 8 more

export type IntegrationEvent = VideoUploadedEvent | VideoTranscodedEvent | /* ... */
export const IntegrationEventSchema = z.discriminatedUnion('name', [VideoUploadedEventSchema, /* ... */])
```

## Rust emitter changes

**Drop:** `packages/contracts/generated/rs/src/integration_event.rs` (the stopgap declarative macro)

**New emission shape** (per event in `generated/rs/src/wire/events.rs`):
```rust
use template_framework_macros_rs::integration_event;
use crate::wire::enums::*;

integration_event!("integration.video.uploaded" => VideoUploadedEvent {
    video_id: z.string(),
    channel_id: z.string(),
    uploaded_by: z.string(),
    byte_size: z.int(),
    mime_type: z.string(),
    storage_key: z.string(),
});
```

**Field-type → z.* DSL mapping** (in `emit-wire-rs.ts`):
- `string` → `z.string()`
- `integer int64` → `z.int()` (the framework macro DSL doesn't distinguish 32 vs 64 directly; it picks via inference)
- `integer int32` → `z.int()` (same)
- `number` → `z.f64()` if available, else `z.f32()`
- `boolean` → `z.boolean()`
- `date-time` → `z.date()`
- `url` → `z.string()` (no native url type in DSL; document as TODO)
- `enum-ref X` → `z.r#enum(X)` (X resolves through `crate::wire::enums::X`)
- `unknown` → `z.string()` with TODO

**lib.rs generated content changes:**
```rust
// AUTO-GENERATED — do not edit.
pub mod wire;
// (no more `#[macro_use] pub mod integration_event;` — macro comes from framework)
```
