# P1.6 — Port framework/rs from feat/polyglot

**Goal:** Copy Rust framework primitives (types, errors, db, events, jobs, middleware, repositories, services, utils) and the proc-macros crate (entity!, value_object!, *_event!, event_handler!, job!, discriminated_union!, dto!, error_codes!, traced_impl) from `feat/polyglot:packages/api-rs/` to `packages/framework/rs/`. Wire the Cargo workspace.

**Source:** `feat/polyglot:packages/api-rs/src/shared/` + `feat/polyglot:packages/api-rs/macros/`

**Result layout:**
```
packages/framework/rs/
├── Cargo.toml                # template-framework-rs lib crate
├── src/
│   ├── lib.rs                # re-exports + #[macro_use] hooks
│   ├── types/                # Entity, Schema, BaseError, Id, DomainEvent, IntegrationEvent, Handler, Job, UnitOfWorkFactory, Tx, BoundedContext
│   ├── errors/               # BaseDomainErrors, BaseApplicationErrors, BaseInterfaceErrors, BaseInfrastructureErrors, ApiError barrel
│   ├── db/                   # pagination, pg_enum, pool, with_exec
│   ├── repositories/         # domain_event_repository trait + Pg/Mock impls
│   ├── services/             # internal_mediator (channel), external_mediator (log/redis), outbox, scheduler
│   ├── jobs/                 # JobRunner, scheduler
│   ├── middleware/           # trace_context, auth (generic)
│   └── utils/                # config, telemetry, global_error_mapper
└── macros/
    ├── Cargo.toml            # template-framework-macros-rs proc-macro crate
    └── src/
        ├── lib.rs
        ├── dsl.rs            # z.* DSL parser
        ├── field_plan.rs     # per-field codegen
        ├── entity.rs
        ├── value_object.rs
        ├── event.rs          # domain_event! + integration_event!
        ├── event_handler.rs
        ├── error_codes.rs
        ├── discriminated_union.rs
        ├── dto.rs
        └── traced.rs
```

**Not lifted (left in api-rs context, removed from clean-polyglot since we have video-streaming domain):**
- `shared/container.rs` — DI container; per-app
- `shared/controllers/listen_events.rs` — SSE controller; api-rs concrete
- `shared/events/game_announced.rs`, `user_logged_in.rs` — context events
- `shared/jobs/sample_job.rs` — example job
- `shared/middleware/auth.rs` — context-specific auth check; if generic, could lift later
- `shared/mod.rs` — barrel; rewrite to point at framework
