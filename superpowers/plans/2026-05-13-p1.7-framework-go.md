# P1.7 — Port framework/go from dev:packages/channel

**Goal:** Copy Go framework primitives (config, db, entities, enums (generic), errors, middleware, objects (generic), repositories, services, types, module.go) and pkg utilities (httputil, openapi, validation) from `dev:packages/channel/` to `packages/framework/go/`.

**Source:** `dev:packages/channel/internal/shared/` + `dev:packages/channel/pkg/`

**Result layout:**
```
packages/framework/go/
├── go.mod                    # module: template/framework-go; go 1.23
├── config/                   # Config struct, env loading, validation
├── db/                       # PG client, embedded migrations infra, dbutil
├── entities/                 # BaseEntity (UUID + domain event collector)
├── enums/                    # Environment, Platform, Country, Currency, LogLevel, Language (generic only)
├── errors/                   # AppError, ErrorCode, HTTP mapper
├── middleware/               # APIKey, CORS, Logging, Recovery, Session
├── objects/                  # ID, Address (generic VOs; CNPJ if generic enough)
├── repositories/             # DomainEventRepository interface + PG impl
├── services/
│   ├── httprouter/           # fx-integrated HTTP router
│   ├── mediator/             # InternalMediator (channel) + ExternalMediator (Redis)
│   ├── outbox/               # OutboxDispatcher (poll + retry + per-owner concurrency)
│   └── unitofwork/           # UoW interface + Noop impl
├── types/                    # DomainEvent[T], IntegrationEvent[T], Controller, Handler[I,O], Middleware
├── module.go                 # Shared fx.Module wiring
└── pkg/
    ├── httputil/             # ErrorResponse, RespondJSON, RespondError
    ├── openapi/              # reflection-based OpenAPI 3.1 emitter
    └── validation/           # validator/v10 wrapper
```

**Not lifted (context-specific — would go to api/go in P4):**
- `internal/channel/*` — entire channel bounded context (entities, controllers, handlers, projections, repositories, services/gateway)
- `internal/shared/db/sql/migrations/*.sql` — channel migrations (canonical schemas now in contracts/db)
- `internal/shared/events/` — channel events
- `internal/shared/objects/CNPJ.go` if it's medscall-specific Brazilian

## Tasks (compressed)

**T1: Copy internal/shared/ to framework/go/**
```bash
git checkout dev -- packages/channel/internal/shared
mkdir -p packages/framework/go
# Move each subdir to framework/go root (drop internal/shared/ prefix)
for dir in config db entities enums errors middleware objects repositories services types; do
  git mv packages/channel/internal/shared/$dir packages/framework/go/$dir 2>/dev/null || echo "(no $dir)"
done
git mv packages/channel/internal/shared/module.go packages/framework/go/module.go 2>/dev/null
git mv packages/channel/internal/shared/controllers packages/framework/go/controllers 2>/dev/null
# Drop migrations (those are context-specific channel schemas)
rm -rf packages/framework/go/db/sql/migrations
# Drop any other context-specific bits
rmdir packages/channel/internal/shared 2>/dev/null
```

**T2: Copy pkg/ to framework/go/pkg/**
```bash
git checkout dev -- packages/channel/pkg
mkdir -p packages/framework/go/pkg
for f in $(ls packages/channel/pkg/); do

done
rmdir packages/channel/pkg 2>/dev/null
```
