**T4: Post-drizzle GIN-index preservation**

Create `packages/contracts/codegen/post-drizzle.ts`:
```typescript
import { writeFile, readFile } from 'node:fs/promises'

const SQL = `CREATE INDEX IF NOT EXISTS "search_index_tsv_idx" ON "search"."search_index" USING GIN ("tsv");\n`
const SQL_PATH = 'db/migrations/0001_search_gin_index.sql'
const JOURNAL = 'db/migrations/meta/_journal.json'
const TAG = '0001_search_gin_index'

await writeFile(SQL_PATH, SQL)
const j = JSON.parse(await readFile(JOURNAL, 'utf-8'))
if (!j.entries.find((e: { tag: string }) => e.tag === TAG)) {
	j.entries.push({ idx: 1, version: '7', when: Date.now(), tag: TAG, breakpoints: true })
	await writeFile(JOURNAL, JSON.stringify(j, null, 2))
}
console.log(`✔ post-drizzle: added ${TAG}`)
```

Add `drizzle:post` script in contracts package.json:
```json
"drizzle:post": "bun codegen/post-drizzle.ts"
```
